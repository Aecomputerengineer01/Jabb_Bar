## 1. ตาราง: `DrinkItem` (รายการสต็อกเครื่องดื่มปัจจุบัน)

ตารางหลักสำหรับเก็บข้อมูลสต็อกของเครื่องดื่มทั้ง 41 รายการในปัจจุบัน:

| ชื่อคอลัมน์ (Column Name) | ชนิดข้อมูล (Data Type) | Nullable | ค่าเริ่มต้น (Default) | Constraints / Keys | คำอธิบาย (Description) |
| :--- | :--- | :---: | :---: | :---: | :--- |
| **`id`** | `TEXT` (CUID) | No | `cuid()` | Primary Key | รหัสเฉพาะของเครื่องดื่ม |
| **`no`** | `INTEGER` | No | - | Unique | ลำดับการแสดงผลในตาราง (1 ถึง 41) |
| **`name`** | `TEXT` | No | - | - | ชื่อเครื่องดื่ม (เช่น "แบล็ค", "รีเจนซี่ แบน") |
| **`category`** | `TEXT` | No | - | - | รหัสหมวดหมู่ (whisky, beer, soju, ฯลฯ) |
| **`unit`** | `TEXT` | No | `"ขวด"` | - | หน่วยนับ (ขวด, กระป๋อง, กล่อง, ลัง) |
| **`broughtForward`** | `INTEGER` | No | `0` | - | **(A)** ยอดยกมาจากรอบกะก่อนหน้า |
| **`added`** | `INTEGER` | No | `0` | - | **(B)** จำนวนสินค้าที่สั่งเพิ่มใหม่ในกะนี้ |
| **`cFront`** | `INTEGER` | No | `0` | - | สต็อกนับเปิดร้าน: จุดหน้าร้าน (บาร์หลัก) |
| **`cBack`** | `INTEGER` | No | `0` | - | สต็อกนับเปิดร้าน: จุดหลังร้าน (ห้องเก็บของ) |
| **`dFront`** | `INTEGER` | No | `0` | - | สต็อกนับคงเหลือปิดร้าน: จุดหน้าร้าน |
| **`dBack`** | `INTEGER` | No | `0` | - | สต็อกนับคงเหลือปิดร้าน: จุดหลังร้าน |
| **`remark`** | `TEXT` | Yes | `NULL` | - | ข้อความหมายเหตุเพิ่มเติม |
| **`createdAt`** | `TIMESTAMP(3)` | No | `now()` | - | วันเวลาที่สร้างเรคคอร์ด |
| **`updatedAt`** | `TIMESTAMP(3)` | No | `now()` | - | วันเวลาที่แก้ไขล่าสุด (Auto-update) |

> 💡 **ฟิลด์ที่คำนวณอัตโนมัติ (Computed in API / UI):**
> - **`(C) รวมร้านเปิด`** = `cFront + cBack`
> - **`(D) คงเหลือร้านปิด`** = `dFront + dBack`
> - **`(E) ขาย (Sold)`** = `(cFront + cBack) - (dFront + dBack)`
> - **`hasWarning`** = `(cFront + cBack) != (broughtForward + added)`

## 2. ตาราง: `DailyShift` (ประวัติการปิดยอดกะประจำวัน)

ตารางเก็บบันทึกสรุปภาพรวมในแต่ละค่ำคืนที่มีการกดปุ่ม "ปิดยอดประจำวัน":

| ชื่อคอลัมน์ (Column Name) | ชนิดข้อมูล (Data Type) | Nullable | ค่าเริ่มต้น (Default) | Constraints / Keys | คำอธิบาย (Description) |
| :--- | :--- | :---: | :---: | :---: | :--- |
| **`id`** | `TEXT` (CUID) | No | `cuid()` | Primary Key | รหัสเฉพาะของประวัติกะ |
| **`shiftDate`** | `TEXT` | No | - | - | วันที่ของรอบกะ รูปแบบ `YYYY-MM-DD` |
| **`closedAt`** | `TIMESTAMP(3)` | No | `now()` | Index | วันที่และเวลาเป๊ะๆ ที่กดปุ่มปิดยอด |
| **`totalSold`** | `INTEGER` | No | `0` | - | ยอดรวมจำนวนขวดที่ขายได้ทั้งหมดในกะนี้ |
| **`totalOpenStock`** | `INTEGER` | No | `0` | - | ผลรวมสต็อกเปิดร้านทั้งหมดในกะนี้ $(C)$ |
| **`totalCloseStock`**| `INTEGER` | No | `0` | - | ผลรวมสต็อกคงเหลือปิดร้านที่ยกไปวันถัดไป $(D)$ |
| **`warningCount`** | `INTEGER` | No | `0` | - | จำนวนรายการที่มีปัญหายอดเปิดร้านไม่ตรง |
| **`notes`** | `TEXT` | Yes | `NULL` | - | บันทึกสรุปประจำวันจากผู้จัดการกะ |

## 3. ตาราง: `ShiftRecord` (สแนปช็อตเครื่องดื่มรายขวดในแต่ละกะ)

ตารางบันทึกตัวเลขสต็อกของเครื่องดื่มแต่ละรายการ ณ วินาทีที่กดปิดกะ:

| ชื่อคอลัมน์ (Column Name) | ชนิดข้อมูล (Data Type) | Nullable | Constraints / Keys | คำอธิบาย (Description) |
| :--- | :--- | :---: | :---: | :--- |
| **`id`** | `TEXT` (CUID) | No | Primary Key | รหัสเฉพาะของสแนปช็อตเรคคอร์ด |
| **`shiftId`** | `TEXT` | No | Foreign Key | เชื่อมโยงกับ `DailyShift.id` (`onDelete: Cascade`) |
| **`drinkId`** | `TEXT` | Yes | Foreign Key | เชื่อมโยงกับ `DrinkItem.id` (`onDelete: SetNull`) |
| **`drinkName`** | `TEXT` | No | - | สำเนาชื่อเครื่องดื่ม ณ ขณะปิดกะ |
| **`category`** | `TEXT` | No | - | สำเนาหมวดหมู่ ณ ขณะปิดกะ |
| **`broughtForward`** | `INTEGER` | No | - | ยอดยกมา $(A)$ ของวันนั้น |
| **`added`** | `INTEGER` | No | - | สั่งเพิ่ม $(B)$ ของวันนั้น |
| **`cTotal`** | `INTEGER` | No | - | รวมเปิดร้าน $(C)$ ของวันนั้น |
| **`dTotal`** | `INTEGER` | No | - | คงเหลือปิดร้าน $(D)$ ของวันนั้น |
| **`sold`** | `INTEGER` | No | - | ยอดขาย $(E)$ ของขวดนี้ในวันนั้น |
| **`remark`** | `TEXT` | Yes | - | หมายเหตุของขวดนี้ในวันนั้น |
