## 1. การออกแบบเพื่อสภาพแวดล้อมแสงน้อย (NFR-01: Dark Mode & Low-Light Usability)

```text
┌─────────────────────────────────────────────────────────────┐
│                 NIGHTLIFE COLOR PALETTE                     │
│                                                             │
│   Obsidian Deep    Slate Navy        Neon Emerald (Sold)    │
│     #07090e         #121723               #10b981           │
│   [Main Canvas]   [Cards / Rows]    [Highest Visibility]   │
│                                                             │
│    Neon Amber      Neon Rose (Warn)       Ice Cyan          │
│     #f59e0b           #f43f5e              #06b6d4          │
│   [Brand / Date]   [Mismatch Alert]     [Added Stocks]      │
└─────────────────────────────────────────────────────────────┘
```

1. **ลดแสงสะท้อนและลดความเมื่อยล้าสายตา (Eye Strain Reduction):**
   - ใช้โทนสีพื้นหลังหลักเป็น **Obsidian Deep (`#07090e`)** และการ์ดย่อยเป็น **Slate Navy (`#121723`, `#181f2f`)** เพื่อไม่ให้แสงจากหน้าจอมือถือสว่างจ้าแยงตาพนักงานและแขกในร้านบาร์
2. **ความคมชัดและอัตราส่วน Contrast (WCAG 2.1 AA Compliance):**
   - ข้อความตัวเลขทั้งหมดใช้สีขาวสว่าง (`text-slate-100`) หรือสีนีออนเรืองแสง ให้ความคมชัดสูงกว่า 7:1 เมื่อเทียบกับพื้นหลัง
3. **การเน้นสีช่องยอดขาย (E) ขาย (Sold) เด่นชัดที่สุด:**
   - ใช้สไตล์ **Neon Emerald Glow**: `bg-emerald-500/20 text-emerald-300 border border-emerald-400/60 shadow-[0_0_15px_rgba(16,185,129,0.35)]` พร้อมตัวเลขอักษรหนาพิเศษ มองเห็นได้ชัดเจนแม้ห่างจากหน้าจอ 1 เมตร

## 2. ความสะดวกในการใช้งานผ่านอุปกรณ์พกพา (NFR-02: Mobile & Tablet Ergonomics)

1. **Touch Target Accessibility:**
   - ปุ่มกดทั้งหมด (ปุ่มบวกเลข, ปุ่มปิดยอด, ชิปเลือกหมวดหมู่) ต้องมีขนาดพื้นที่แตะสัมผัส **ไม่ต่ำกว่า 44 × 44 pixels** ตามมาตรฐาน Apple Human Interface Guidelines
2. **Numeric Keypad Triggering:**
   - ช่องกรอกตัวเลขทุกช่องต้องกำหนดแอตทริบิวต์ `inputMode="numeric"` เพื่อให้ระบบปฏิบัติการ iOS และ Android เรียก **แป้นพิมพ์ตัวเลข (Numeric Keypad)** ขึ้นมาทันทีโดยอัตโนมัติ
3. **Auto-Select on Focus:**
   - เมื่อแตะลงในช่อง Input ตัวเลขเดิมจะต้องถูกไฮไลท์เลือกทั้งหมดทันที (`e.target.select()`) ทำให้พนักงานสามารถพิมพ์ตัวเลขใหม่ทับได้ทันทีโดยไม่ต้องกดย้อนลบตัวเลขเดิม
4. **Horizontal Scroll with Sticky Header & Columns:**
   - เมื่อเปิดบนมือถือหรือแท็บเล็ตที่มีความกว้างน้อยกว่าตาราง คอลัมน์ **# (ลำดับ)** และ **ชื่อเครื่องดื่ม** จะถูกตรึง (CSS Sticky) อยู่ทางซ้ายเสมอ เพื่อไม่ให้พนักงานสับสนว่ากำลังกรอกเครื่องดื่มชนิดใดอยู่

## 3. ประสิทธิภาพการทำงาน (NFR-03: Performance & Responsiveness)

1. **Instant Calculation Latency:**
   - การคำนวณยอด $(C)$, $(D)$ และ $(E)$ ต้องประมวลผลบน Client-Side Memory ให้เสร็จสิ้นภายในเวลา **น้อยกว่า 16 milliseconds (60 FPS)** ทุกครั้งที่มีการป้อนตัวเลขอักขระ
2. **Bundle Size & Fast Loading:**
   - โค้ด JavaScript สำหรับ Production ต้องผ่านการทำ Tree-shaking และ Minification โดยมีขนาดไฟล์ Gzip รวม **ไม่เกิน 100 KB** เพื่อให้โหลดแอปได้เร็วแม้สัญญาณอินเทอร์เน็ตในร้านบาร์จะอ่อน
3. **Debounced Local Storage Auto-Save:**
   - บันทึกข้อมูลลง `localStorage` ทันทีที่มีการเปลี่ยนแปลง โดยมีไฟสถานะสีเขียวยืนยันเวลาบันทึกเรียลไทม์

## 4. ความปลอดภัยและความถูกต้องของข้อมูล (NFR-04: Reliability & Data Integrity)

1. **Atomic Transaction for Next Day Shift:**
   - การปิดยอดประจำวันในฐานข้อมูล PostgreSQL ต้องดำเนินการภายใต้ **Prisma `$transaction`** หากมีข้อผิดพลาดเกิดขึ้นระหว่างการบันทึก ระบบจะ Rollback คืนค่าเดิมทันที ข้อมูลสต็อกต้องไม่มีทางเสียหายหรือหายไปครึ่งหนึ่ง
2. **Offline-First Resilience:**
   - หากเซิร์ฟเวอร์ Backend หรือสัญญาณเครือข่ายขัดข้อง หน้าเว็บต้องยังคงทำงานได้ต่อเนื่อง 100% โดยอาศัย Local Storage และจะซิงค์ข้อมูลกับฐานข้อมูลเมื่อกลับมาเชื่อมต่อได้

## 5. ความสะดวกในการติดตั้งและบำรุงรักษา (NFR-05: Portability & Containerization)

1. **Single-Command Docker Orchestration:**
   - ทั้งระบบ (Frontend, Backend, Database) ต้องสามารถเปิดใช้งานได้บนเครื่องใดก็ได้ที่มี Docker ติดตั้งอยู่ ด้วยคำสั่งสั้นๆ เพียงคำสั่งเดียว:
     ```bash
     docker compose up --build -d
     ```
2. **Environment Variable Configuration:**
   - พอร์ตการทำงาน, รหัสผ่านฐานข้อมูล และการตั้งค่าระบบ ต้องสามารถปรับแต่งได้ผ่านไฟล์ `.env` โดยไม่ต้องแก้ไขโค้ดโปรแกรม
